# 검사의 던전 (핵앤슬래시 시험판)

- 12분 던전 원정 · 레벨 업 카드 · 공격 스킬·진화 · 정예·보스 · 주운 장비는 모두 들고 귀환 · 마을에서 영구 강화
- 직업 넷(검사 · 궁수 · 권총수 · 마법사) · 던전 넷(지하 묘지 · 짐승 굴 · 고블린 요새 · 거인 골짜기)
- 장비: 무기·갑옷은 청동 → 강철 → 미스릴 → 룬(뒤 던전일수록 높은 단계) · 주울 때 더 좋으면 바로 낌 · 낀 것과 수치 ▲▼ 비교
- 가로 화면 · 왼손으로 화면 왼쪽을 눌러 끌면 이동 · 적이 가까이 오면 저절로 공격 · 스킬도 저절로
- 오른손: 직업 기술(찌르기·도약·구르기·순간 이동 · 잠깐 무적) · 필살기(재사용 대기)
- PC: WASD/방향키 · Space 직업 기술 · 3 필살기 · Esc 일시정지
- 폰에 설치: 크롬으로 열고 출정 화면의 «폰에 앱으로 설치»(또는 ⋮ → 홈 화면에 추가)
- 배경음: 마을 · 던전마다 한 곡(시간이 갈수록 세짐) · 보스 곡 — 설정에서 켜고 끄기·크기

그림은 전부 이 게임을 위해 새로 만든 것입니다(3D 인형으로 움직임을 뽑아 도트로 마감).
배경음·효과음도 녹음이나 음악 파일 없이 게임이 코드로 직접 연주합니다.
